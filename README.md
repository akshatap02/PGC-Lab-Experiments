Parallel and GPU computing lab experiments, run on WSL2 Ubuntu (and VMs / an NVIDIA GPU where noted).

| Experiment | Topic | Folder |
|---|---|---|
| 1 | Matrix multiplication: sequential, OpenMP, MPI, CUDA | [exp1-matrix-multiplication](exp1-matrix-multiplication) |
